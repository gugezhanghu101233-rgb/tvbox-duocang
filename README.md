# TVBox / 影视仓 多仓聚合

个人自用多仓接口（JSON格式）。

## 使用方法

1. 打开影视仓 或 TVBox
2. 进入 **设置 → 配置地址**（有的叫「订阅」「仓库」）
3. 填入下面地址：

### 推荐加速地址

```
https://gh-proxy.com/https://raw.githubusercontent.com/gugezhanghu101233-rgb/tvbox-duocang/main/duocang.json
```

### 原始地址

```
https://raw.githubusercontent.com/gugezhanghu101233-rgb/tvbox-duocang/main/duocang.json
```
